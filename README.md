# HakSeupJi
성신(성공의 신화) 국어 학습지를 만드는 Claude 스킬 패키지

- `HakSeupJi/`: 학습지 스킬 (makeone · bind · makeall · final)
- `grammar-checker/`: 맞춤법 검사 스킬 ([daleseo/korean-skills](https://github.com/daleseo/korean-skills), MIT). 학습지 마지막 단계에서 자동 실행
- `setup.sh`: Claude Code 자동 세팅 (`bash setup.sh`)

사용법은 [01_선생님용_사용안내.md](01_선생님용_사용안내.md)를 보세요.
Claude Code에 `HakSeupJi.zip`을 넣고 "세팅해 줘"라고만 하면 Claude가 [00_클로드가_먼저_읽을_것.md](00_클로드가_먼저_읽을_것.md) 순서대로 설치합니다.
